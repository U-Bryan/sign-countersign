# Minimum identity checklist for A2A deployments

One page. Each item names the experimental evidence behind it. The A2A column was checked against the Agent2Agent (A2A) Protocol Specification, version 1.0.0 (https://a2a-protocol.org/latest/specification/, read 7 November 2026); section numbers refer to that version.
