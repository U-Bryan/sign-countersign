# Minimum identity checklist for A2A deployments

One page. Each item names the experimental evidence behind it. The A2A column was checked against the Agent2Agent (A2A) Protocol Specification, version 1.0.0 (https://a2a-protocol.org/v1.0.0/specification/, read 7 November 2026); section numbers refer to that version. In short, A2A v1.0.0 authenticates requests and encrypts connections but leaves message signing, replay protection and the treatment of authenticated content to the deployment.
